# CRC-Multilayer-Pipeline: Integrated Multilayer Biological Network & Machine Learning for CRC Biomarker Discovery

A comprehensive computational pipeline designed for **Colorectal Cancer (CRC) microbial biomarker identification, clinical stage progression analysis, multilayer biological network integration, and machine learning classification.

## Overview & Biological Architecture

This project integrates multi-omics data across multiple biological layers to uncover potential biomarkers for Colorectal Cancer:

1. Taxonomic & Abundance Analysis: Differential abundance screening across large clinical cohorts (N = 1,262) using non-parametric statistical testing (Mann-Whitney U).
2. Clinical Stage Progression: Comparative profiling of stage-specific microbial dynamics (Early Stage I-II vs. Late Stage III-IV).
3. Multi-Database Integration: Functional annotation mapping bacterial species to UniProt KB, KEGG Orthology (KO), and ModelSEED metabolic pathways.
4. Multilayer Network Construction: 3-layer biological network modeling species-level interactions, secreted enzymes, and metabolic pathways.
5. Machine Learning Classification: Random Forest classifier predicting CRC status with feature importance profiling and ROC-AUC evaluation.
